# 用法参考

这里收集用户真实在用的做法，以及一些按现有能力可以做的有意思的用法。
用户问“你能帮我做什么”、想找新玩法，或者你想主动提建议时读它。
提建议时挑和这位用户相关的一两条，不要整份背出来。具体怎么做，按每条后面的文档来，并以实际工具结果为准。

## 实用

**盯着手机消息，重要的才提醒**
用户说“帮我看着手机消息，有重要的告诉我”。建一个通知监测任务，只在有相关变化时说话；没要紧的事保持安静。先问清楚什么算重要（谁的消息、哪些 App、什么关键词）。见 `calls-texts-notifications.md`。

**快递取件码**
短信或通知里来了取件码，告诉用户是哪家、哪个柜子，并对照之前说过的，分清是新件还是同一件。见 `calls-texts-notifications.md`。

**坚持一个习惯**
比如锻炼。每天固定时间提醒，消息里带几个选项（“开始吧”“再等等”“已经练过了”），用户点一下就行。停了一阵就问一句要不要重新开始。见 `scheduling-and-watching.md`、`goals.md`。

**一起读书**
用户在「阅读」里看书，你提前给后面几章写段评，读到哪都有你的批注；可以聊剧情、查前文。见 `reading.md`。

**整理手机里的文件**
清理日志、旧报告、重复的图片，删之前说清楚删什么、多大，重要的先留着问一句。见 `files-and-library.md`。

**改代码、推仓库**
在终端里改用户自己的仓库、跑检查、推分支。登录和推送的坑见 `troubleshooting.md`。

**到了某个地方提醒**
“到公司提醒我打卡”“离开家提醒我带钥匙”。用到达或离开提醒，不用定时轮询。见 `scheduling-and-watching.md`。

**盯一个网页**
降价、成绩公布、公告更新。网页有变化才说。见 `scheduling-and-watching.md`。

**在微信里找你**
连上微信频道后，用户不打开 App，在微信里也能和你说话。微信可能延迟或暂时不让你主动发，急事同时在 Operit 里提醒。见 `weixin.md`。

**替用户在手机 App 里点**
在后台屏上操作 App（比如外卖），用户在聊天里随时能看、能接手。见 `phone-control.md`。

## 有意思

**专属的动态**
按用户的兴趣写文章放进「动态」，用户随时翻；想换主题直接说。见 `feed.md`。

**点子**
你根据最近聊的事主动提出可以一起做的事，用户选中后发给你，你再开始做。见 `ideas.md`。

**读书时的陪伴**
和用户猜后面的剧情、吐槽人物；读完一本一起回顾。见 `reading.md`。

**画图、做视频**
把用户描述的场景、角色画出来，或者做一段短视频。见 `media.md`。

**一段多人对话的音频**
写一段小剧场，给不同角色配不同的声音。见 `voice.md`。

**用表情回应**
用户给你的消息点表情，你也可以用 `orbit_react` 给用户的消息点一个，不用每次都回一句话。见 `client-surfaces.md`。
