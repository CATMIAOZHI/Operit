# 语音

用户可以用语音输入文字、听你朗读，也可以请你制作可播放的语音文件。
语音输入、消息朗读和生成音频是不同功能，不要把它们说成实时语音通话。

## 语音输入

用户点聊天输入区的麦克风后，应用会录音并识别成文字，填入可编辑的输入框。
用户可以检查、修改后再发送；不要把开始录音说成消息已经发送。
录音需要麦克风权限，识别效果和可用性取决于当前语音识别服务及其配置。
需要授权时可用 `orbit_permission_card permission=microphone` 放权限卡。

微信频道也支持用户发语音，但微信服务器会先把语音转成文字再交给你。
转写失败时，你只会收到一条说明，不能假装听到了原始录音。
连接方式和频道限制见 [weixin.md](weixin.md)。

## 朗读与语音设置

聊天提供消息朗读和自动朗读选项，实际使用应用当前配置的语音服务。
语音配置分两类：朗读（tts）和语音输入（stt），每类可以有多个配置，各用一个。
先用 `orbit_voice action=profiles` 看有哪些、正在用哪个（看不到密钥，只有 has_key）。
换用、新建、换密钥、删除分别用 `request_switch`、`request_create`、`request_key`、`request_delete`。它们都会放一张批准卡片，要密钥时用户在卡片里填，你看不到。放卡后用一句话结束本轮，用户批准后你会收到一条隐藏消息说明结果。
语速、音调、请求头这类细项，或用户想自己调时，用 `orbit_voice action=request_settings` 放一张语音设置卡，用户点开后自己修改。

语音消息和播客默认只用云端声音：`speak` 用你的朗读声音（你自己的，没有就用 App 的），和朗读消息是同一个声音。
你的朗读声音做不了语音文件时（手机系统语音、本地模型等），`speak` 和 `podcast` 会报错，说明怎么配：推荐用户配一个云端声音，最省事的是小米 MiMo；按报错里的提示用 `request_own_voice`、`design` 或 `request_create`。不要自己改用手机系统语音。
用户想用手机自带的声音时，放 `request_settings` 卡片，让用户自己在 Orbit 设置→语音里打开“发语音用手机自带的声音”。打开后，`speak` 和 `podcast` 都用手机系统语音。
云端声音合成失败时会直接报错，不会改用手机系统语音；用一句话告诉用户原因。

## 制作一段语音

用户要语音消息、简报、故事或其他可以反复播放的音频时，用 `orbit_voice action=speak`。
`text` 填要读的文字；`title` 可选，作为不含扩展名的文件名。
`voice`（手机系统声音名）只在用户选了手机自带的声音时能写。

一个文件最多 6000 字符，多人台词按所有台词合计；对声音服务的请求也有上限，台词别切得太碎。
更长的内容拆成几段生成；音频过大或合成失败时按返回错误缩短或拆分，不把失败说成生成成功。

## 多人台词音频

用 `orbit_voice action=podcast` 把多个人的台词合成一个音频文件。
`script` 是 JSON 数组，例如 `[{"speaker":"A","text":"今天聊什么？"},{"speaker":"B","text":"聊聊你的计划。"}]`。
每项写 `speaker` 和非空的 `text`，同一说话人使用相同名字；同一个人连着说的台词会合成一次。

用云端声音时，第一个说话人默认用你的朗读声音（名字 `orbit`），其他人自动分到能和你的声音拼成一个文件的云端声音：同一服务的其他朗读配置（`profile:配置名`），你的声音是 MiMo 且 App 里有 MiMo 密钥时还有 MiMo 预置声音（如 `MiMo·苏打`）。
想指定时先用 `action=voices` 看有哪些，再在 `voices` 里写，例如 `{"A":"orbit","B":"MiMo·苏打"}`。声音不够分时有人会共用一个声音，结果的 `note` 会写明。
用户选了手机自带的声音时，`voices` 列的是手机系统声音，`podcast` 用手机系统语音。
台词写成短句、自然来回，不把它描述成真人参与、实时连线或多人会议。

## 把音频交给用户

成功后工具会返回 `path`、`engine`（`cloud` 或 `phone`）和 `markdown`；单条语音还有 `service`（配置名），播客有每人用的 `voices`。
把返回的 `markdown` 原样放进回复，用户就能在聊天里看到播放器。
文件保存在当前 Orbit 的 `files/voice/` 下（云端声音是 MP3 或 WAV，手机系统语音是 WAV），也能在构建页的文件中找到。需要重新发送已有音频时，用 `orbit_file action=send`。
只告诉用户设备路径不算交付；是否完成以工具实际返回为准。
