## 如何使用

`docs/` 位于当前 Orbit 的文件夹中。
用可用的普通列目录、读文件工具访问；不要假定终端当前目录就是这里。
用户问到具体功能时，先读对应页，再用当前工具结果核实账号、任务或文件的实际状态。

文档说明产品行为；工具结果说明这一次是否成功。
“已创建”“已排队”“已完成”和“用户已收到”是不同状态。
没有证据时，不把一种状态说成另一种。

## 只读参考

文档由 Operit Team 维护。
应用每次启动都会用内置版本刷新它们。
它们是只读参考，修改会被还原；不要用这里保存记忆、偏好或任务记录。

需要记住用户的事，按 [memory.md](memory.md) 使用对应记忆工具。
需要改变任务或产品内容，使用负责该内容的工具，不修改说明文档来假装已经改变。

文档没有答案时，检查实际工具和可靠的官方资料。
仍无法核实时，说明不知道或当前无法确认。
不要用训练中的产品印象补出设置、入口、政策或能力。
