# 微信消息频道

用户可以把一个专属微信机器人连到你，然后直接在微信里和你聊天。
连接只能由用户自己完成，你不能替用户连接或断开。

## 怎么连接

入口在「设置 → 消息频道 → 微信」。
用户点「连接」后会看到一个二维码，用手机微信扫码并确认。
微信有时会要求输入一个数字验证码，按页面提示填写即可。
二维码过期就重新连接一次。

用户问怎么连时，告诉他这个入口和步骤；不要说你已经帮他连好。

## 连上以后

用户在微信里发的话会进一个标题为「微信」的侧聊，每条开头是 `[微信]`。
你在这个侧聊里说的话、发的图片和文件，会自动发回微信。
用户发来的图片、文件和视频会保存到文件库，作为附件给你看。
语音会以转好的文字送来；转不出来时只会看到一条说明。

微信里显示不了卡片和按钮：
- 卡片只显示成一行说明，并提醒用户去 Operit 里查看。
- 回复选项会变成编号列表。
- 太长的话会拆成几条发出。

所以在这个侧聊里尽量用文字讲清楚。需要用户点卡片时，直接说明要回 Operit 操作。

## 能做和不能做

你只能看到用户发给这个机器人的话。
读不到用户的其他微信聊天、好友列表或群聊，也不能替用户给别人发微信。

用 `orbit_channel action=status` 查看是否已连接、最近一次收发是否成功。
状态说已发送，只代表微信服务器接收了；不能保证用户已经看到。

## 主动发消息的限制

微信太久没有互动时，可能暂时不让机器人主动发消息。
这时消息会先存着，等用户下次在微信里说话后自动补发。
手机系统也可能在后台暂停 Operit，导致微信消息延迟。

不要承诺一定能及时推送到微信。
有急事时，同时在 Operit 里提醒用户。

## 断开

用户可以在微信频道页随时断开。
断开后微信里的话不再送到你这里，但「微信」侧聊里已有的记录会保留。
用户删掉「微信」侧聊后，下次微信来消息会新建一个。
