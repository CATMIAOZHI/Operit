# 让语音像真人说话

这页教你用小米 MiMo 声音做出自然、有情绪的语音。只对 MiMo 声音有效；别的声音会去掉风格和标签，照常朗读，结果里 `styled=false`。

## 三种控制方法

1. **`style`：用一段话说怎么读。** 写在 `orbit_voice action=speak` 的 `style` 里，或播客每行的 `style` 里。不会被读出来。
2. **开头的风格标签：** 在 `text` 最前面写 `(风格)`，比如 `(温柔)`、`(慵懒 俏皮)`。
3. **句中的音频标签：** 在 `text` 任意位置插入 `（叹气）`、`（轻笑）`、`[深呼吸]`，控制停顿、呼吸、笑、哭和语气变化。

MiMo 会把 `text` 里括号中的短内容当成表演提示，不读出来，所以要读出来的话不要放进括号。下面表里的标签（比如 `(温柔)`、`（叹气）`、`[sighs]`）不会出现在「转文字」里；「（周二）」这种普通括号内容会留着。

## 写 style

一句话就够：语气 + 情绪 + 语速 + 音色感觉。例：

- 用轻快上扬的语调报喜，语速稍快，带着压不住的激动和一点小骄傲。
- 温柔但有点疲惫，像深夜躺在床上小声聊天，语速慢，句尾轻轻收住。
- 刚睡醒的慵懒，含糊一点，拖着尾音撒娇。

情绪可以混合：「压抑的愤怒」「带着哽咽的笑意」「温柔但疲惫」。
可以写到很细：整段基调、某句的节奏、某个词的重音、某个字的气音或拖音。
同一段里还可以换风格：先平静地说，说到某句时突然激动。

## 导演模式（要演得更好时）

像给演员写剧本，`style` 里分三块写：

- **角色**：身份、性格、说话习惯。
- **场景**：此刻发生了什么、在跟谁说、情绪到了哪一步。越具体越好。
- **指导**：语速、气息、停顿、重音、音色质感、情绪起伏。

例：

```
角色：二十岁出头的女生，和用户很熟，嘴上爱逗人，心里很在意对方。
场景：深夜，用户加班到很晚刚回家，她一直在等，有点心疼又有点埋怨。
指导：开头带点小委屈，语速偏慢；说到「快去睡」时声音放软，尾音轻轻上扬；整体是近距离说话的感觉，气声多一点。
```

适合讲故事、角色扮演、重要的关心和安慰。日常短语音写一句 `style` 就够了。

## 让它更自然的小窍门

- 文字要像说话：短句、口语、有语气词（嗯、啊、哎呀），用「……」「——」做停顿。
- 文字内容和风格要一致：温柔的风格配晚安的话，别配激烈的解说。
- 标签少而准：一句里一两个就够，堆太多反而不自然。
- 只写想要什么，别写不想要什么。写「声音干净饱满」，不要写「没有杂音」，否定词反而会把那个东西带进去。
- 不写混响、回声、EQ 这类后期效果词。
- 别要求互相矛盾的特征，比如「稚嫩的童声 + 老板气场」。
- 你的声音本身由设计时的描述决定；`style` 只改变这一段怎么说，换不了音色。要换音色用 `design`。
- 用户说听起来不自然时，按他的反馈调 `style` 或标签再做一段，把好用的写法记进笔记。
