# Ways to Use Orbit

What users actually do with Orbit, plus some fun things the current features allow.
Read it when the user asks what you can help with, wants new ideas, or you want to suggest something yourself.
Pick one or two that fit this user; do not recite the whole list. For how to do each, follow the doc it points to and trust actual tool results.

## Practical

**Watch phone messages, speak up only for important ones**
The user says "keep an eye on my messages and tell me about important ones." Create a notification watch that only speaks up when something relevant changes and stays quiet otherwise. First ask what counts as important (whose messages, which apps, which words). See `calls-texts-notifications.md`.

**Parcel pickup codes**
When a pickup code arrives by text or notification, tell the user which company and which locker, and compare with earlier ones to tell a new parcel from the same one. See `calls-texts-notifications.md`.

**Keep up a habit**
Exercise, for example. A reminder at a set time each day, with a few options in the message ("Let's go", "Later", "Already done") so one tap answers. After a lapse, ask whether to start again. See `scheduling-and-watching.md`, `goals.md`.

**Read a book together**
The user reads in Legado (阅读) and you write paragraph comments for the next few chapters ahead, so your notes are there wherever they read; talk about the plot or look back at earlier chapters. See `reading.md`.

**Tidy files on the phone**
Clear logs, old reports and duplicate images. Before deleting, say what and how much; keep anything important and ask first. See `files-and-library.md`.

**Change code and push a repository**
Edit the user's own repository in the terminal, run checks and push a branch. For sign-in and push pitfalls see `troubleshooting.md`.

**Remind at a place**
"Remind me to clock in when I get to work", "remind me to take my keys when I leave home." Use an arrive or leave reminder, not timed polling. See `scheduling-and-watching.md`.

**Watch a web page**
Price drops, published results, notice updates. Speak only when the page changes. See `scheduling-and-watching.md`.

**Talk in WeChat**
With the WeChat channel connected, the user can talk to you in WeChat without opening the app. WeChat can delay or hold your own messages for a while, so for urgent things also remind them in Operit. See `weixin.md`.

**Tap through phone apps for the user**
Operate an app (food delivery, for example) on your background screen while the user can watch or take over from the chat. See `phone-control.md`.

## Fun

**A Feed of their own**
Write articles on the user's interests into Feed for them to browse anytime; they can change the topics by just saying so. See `feed.md`.

**Ideas**
Suggest things to do together based on recent conversations; when the user picks one and sends it to you, you start. See `ideas.md`.

**Company while reading**
Guess where the plot goes, talk about the characters, look back together after finishing a book. See `reading.md`.

**Pictures and videos**
Draw a scene or character the user describes, or make a short video. See `media.md`.

**An audio scene with several voices**
Write a short skit and give each character its own voice. See `voice.md`.

**Reply with a reaction**
The user can react to your messages, and you can react to theirs with `orbit_react` instead of always replying with words. See `client-surfaces.md`.
