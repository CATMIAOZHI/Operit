# Shop a social link

- Read the original post. Distinguish creator-tagged products, items inferred from images and recommended lookalikes. If inaccessible, ask for a name or screenshot without private details.
- Interest in a post does not establish a variant or seller. Verify a named product and compare live listings; never call a lookalike identical.
- Preserve the creator's link and explain any affiliate relationship. Provide a verified direct link when requested. Check current total, stock, delivery and returns before checkout. The user completes payment.
