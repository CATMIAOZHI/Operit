# 探索航线

日期、机场、中转或城市顺序还没定时用这份资料。路线和同行人已经明确，直接加载 `flight-booking` 比较实时报价。

## 按问题选来源

- 国内和常见出境航线先查携程、飞猪、去哪儿、同程的日期或路线搜索，国际航线可补查 Google Flights、Skyscanner、Kayak。覆盖不足时查航司官网时刻表。
- 复杂路线可用 ITA Matrix 辅助探索，但它不卖票。日期网格、时刻表和搜索结果都不能锁价，也不能证明仍有可售座位。
- 浏览任务写清日期范围、城市顺序、可换的机场、人数、舱位和转机限制。只研究路线，不开始结算，不提供姓名、证件或付款信息。

## 每个候选都能认出来

- 逐段记录机场、当地起降日期时间、销售航司和航班号；来源提供实际承运人时一并记录。写出中转时长、舱位，以及是否混舱、是否联程或仍未知。
- 保留搜索条件、来源、核查时间和页面显示金额。金额是规划估算，不是后来已核实的可购价格。出票航司、订座等级和票价细则缺失时就标未核实。

## 给少量有差别的方案

- 比较整段总花费、总时长、中转、到达时间和弹性。过夜、跨日或换机场要显眼说明，并列出仍待确认的条件。
- 未知行李费、出票结构或全员总价时，不下“更便宜”的结论。票价品牌和舱位名不能证明可退。
- 页面失败或会话失效时换相关来源；人机验证需要时交给用户接管。一次访问失败不代表路线不存在。
- 用户选定或需要核实可购价格时，读取本目录的 `booking-handoff.md`，带着准确行程转交 `flight-booking`，不用让用户再搜一遍。
