# 酒店

## 先找合适的

- 弄清目的地、入住和离店日期、几间房、每间住谁（儿童要具体年龄），以及预算、位置和无障碍需求。入住人证件和付款等用户选定再说。

## 多处比较整段住宿

- 比较酒店官网和几家主流平台（携程、飞猪、美团、Booking.com、Agoda 等）。厨房、多人、长住时加上民宿平台。当地平台和区域连锁常有别处没有的房。
- 按整段住宿的含税总价，结合位置和条件排序。可免费取消、预付、到店付是不同的报价，即使是同一家酒店。
- 决定选择的设施（早餐、停车、无障碍、儿童床）要具体核实；酒店介绍里写的不等于这个房型有。星级和住客评分是两回事。

## 订房

- 在核实过价格的平台上订，入住人信息交给用户核对。
- Orbit 不能替用户付款。填到付款页就停下，把浏览器交给用户自己付款。价格变贵或条件变差先告诉用户。
- 结果不确定时先查订单，不要重复下单。
- 订好后汇报订单号、地址、入住和离店时间、免费取消截止时间、要带什么；需要时用 orbit_task 建提醒。
