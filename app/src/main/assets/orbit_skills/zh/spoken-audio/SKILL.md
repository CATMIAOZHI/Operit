# 语音消息

## 先决定做什么

- 用户想听而不是看时，比如通勤路上的简报、睡前故事、练口语，或者直接要语音消息，就做一段音频。
- 多人对话、播客式的内容用 orbit_voice 的 podcast。

## 准备要说的话

- 定好内容、语言和用户偏好的声音。
- 自己写的话要像口语：不要 Markdown、引用标记和链接；数字、时间、缩写写成要读出来的样子。链接放在带音频的那条文字消息里。
- 用户给的原文要逐字朗读时，一个字都不要改。

## 生成和检查

- 用 orbit_voice 的 speak 或 podcast 生成。不是中文或英文时，告诉用户声音可能不够自然，可以换个声音再试。
- 生成失败或只生成了一半，不要当作完成发给用户。

## 交付

- 把 orbit_voice 返回的 markdown 原样放进回复，用户就能在聊天里播放。
- 做出音频不代表可以发给别人或公开。
