# 补查机票来源

主要来源缺票、漏航司，或用户想扩大比较时读这份。具体核价方法见 [flights.md](flights.md)。

## 去哪里查

- 国内先比较航司官网、携程、飞猪、去哪儿、同程。国际航线可补 Google Flights、Skyscanner、Kayak，以及出发地常用平台。通过搜索找到真实网站，不猜商品或出票链接。
- 航司官网可查会员价、里程票、代金券和完整票价规则，也更方便核实航司直接处理的改签与中断安排。
- 廉价航司和区域航司可能不在大型平台上，或官网有更低价。国内可定向查春秋、九元等官网；国际路线按当地航司补查。行李、选座和支付附加费都计入总价。
- 比价站只提供线索。有些站点跳转给第三方出票，核实实际卖方、出票方和后续退改由谁处理。
- 复杂路线可用 ITA Matrix 等查航线和票价规则，但它不售票；找到候选后仍去真实卖方核实。不要把时刻表或缓存价格当作余票。

## 怎样找到更合适的

- 只有用户允许时才扩大日期、机场或城市顺序。算上机场接驳、多住一晚和额外行李费，再说是否更便宜。
- 用户有里程、会员、代金券或同行优惠时，查实时可兑库存、税费、期限和限制。积分转移可能不可撤销，先核实目标航班可兑，再由用户明确决定。
- 航司不同地区站点可能报价不同，先核实是否限当地居民、当地支付方式，以及币种和汇率；不冒充资格。
- 用户重视灵活性和售后时，把航司直订与便宜的代理票一起比较，不默认官网或第三方一定更好。
- 国内短途航线不合适时，可问用户要不要比较高铁；他需要时再按 trip-transport 技能去 12306 查，不悄悄替换交通方式。
