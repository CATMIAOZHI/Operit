# Codex 账户接入

在模型配置中选择 **OpenAI Codex**，点击 **登录 ChatGPT**，在系统浏览器完成授权后返回应用。无需填写 API Key。所有 Codex 配置共用当前应用中的登录账户；稳定版与开发版各自保存加密凭据。

模型列表读取现有本地模型目录，不隐式刷新。目录没有 OpenAI 数据时使用内置 Codex 基础列表；列表不代表账户授权范围。目录更新使用原有「刷新本地模型目录」入口。

Codex 固定使用账户认证的 Responses 接口，不参与通用协议覆盖。用户选择的思考强度按 Responses 语义传入，工具续轮保留加密思考上下文；底层统一使用流式响应，包括连接测试。额度区域可手动刷新账户的五小时与七天窗口。

附件继续采用个人版已有的按需读取流程，不改成上传全部图片或 PDF。登录等待最多五分钟，取消或超时会释放本地回调监听端口。浏览器授权需要在同一设备完成；应用进程被系统终止后需重新发起登录。
