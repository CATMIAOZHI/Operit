# 宠物陪伴

AI 功能 → 助手配置，默认打开第一项「宠物陪伴」，其后为「虚拟形象配置」「语音唤醒」。
可分别开启应用内显示、跨应用显示和动画。
首次开启跨应用显示时需要系统悬浮窗权限。返回 Operit 后跨应用层隐藏；
如果开启了应用内显示，由应用内宿主接替。通知中的关闭操作只关闭悬浮宠物。

宠物默认停靠左边。拖动松手后，按实际像素距离吸附到最近的屏幕边缘；左右停靠时气泡朝内，
贴上边时气泡在下方，贴下边时气泡在上方。停靠范围避开系统栏、刘海和应用内键盘。
拖动时暂时隐藏气泡，松手后恢复；气泡出现、收起或展开不改变宠物在边缘上的位置。
点击宠物切换任务气泡显示，并播放已配置的打招呼动画；点击没有涟漪或背景反馈。
气泡显示状态与当前宠物的“显示任务气泡”设置同步，应用内和跨应用共用；没有任务时不显示气泡。
点击气泡展开打开对话操作，不提供关闭气泡或停止任务按钮。
多个任务可通过气泡中的“下一任务”切换。结束提示保留约 20 秒，隐藏只影响气泡。

状态订阅 `ChatRuntimeHolder` 的 MAIN/FLOATING 运行槽，运行身份保留运行槽和 chatId，
不启动模型调用。隐藏聊天不会展示。标题跟随聊天元数据更新，不读取流式正文。
当前全局审批请求没有 chatId，因此不将其猜测为某个任务的等待审批状态。

内置水晴喵使用 `assets/pets/shuiqingmiao/spritesheet.webp`：1536×2288，
8 列、11 行，单格 192×208。图集进程内只解码一次，帧号仅在 Canvas 绘制阶段读取。
应用内不可见、悬浮窗隐藏或息屏时销毁对应的动画组合，不获取唤醒锁。
设置保存在独立的 `pet_companion` 偏好文件中，不修改聊天数据。

## 自定义

支持保存多个宠物配置，通过列表选择一个显示。新增时填写名称并选择 GIF、MP4、
PNG/WebP 静态图或 Codex 宠物包格式，然后在「配置动画文件」中逐项选择文件。
每个宠物独立保存外观、动画、气泡和停靠位置，应用内/跨应用显示开关为全局设置。
可移除配置及其全部应用内素材副本，不改动原始导入文件。Codex 格式未选择包时使用内置水晴喵。

普通文件分别配置休息、思考、工具执行、压缩、完成、错误、本轮结束和打招呼。
休息动画为必需项；未配置时仅显示设置页占位，不显示悬浮宠物。其他状态未设置时复用休息文件。
GIF/MP4 状态动画循环；打招呼播放一次后回到当前状态，静态打招呼图片显示 1.5 秒。
文件选择器按配置格式过滤，并校验真实文件格式。成功替换后才清理旧副本；失败保留原配置。

设置页提供实时预览，可调整大小（默认的 60%～160%）、透明度（0%～70%）、
是否显示气泡以及左/右/上/下停靠边缘；也可以直接拖动吸附。气泡随停靠边缘自动朝内显示。
滑块拖动时更新预览，松手后保存并更新两个实际宿主。恢复默认外观不改变素材和位置。

素材支持静态 PNG/WebP、GIF 动画、MP4 视频，或标准 Codex v2 ZIP。
GIF 使用已有 Coil 解码器循环播放；MP4 使用已有 ExoPlayer 静音循环，TextureView 支持透明度与缩放。
动画开关关闭或宿主不可见时暂停；移除宿主或切换素材时释放动画和视频资源。
视频会校验尺寸及实际首帧解码，不能播放的文件不会保存到动画配置。
ZIP 可有一层或多层外目录，
但必须只有一个 `pet.json`，其中 `spriteVersionNumber` 为 `2`，`spritesheetPath`
相对该 JSON 指向 1536×2288 的 PNG/WebP 精灵图；使用标准 8×11 状态布局。
不支持自定义帧网格或自定义动画轨道。单张图片按静态图显示，保持宽高比。

文件上限 16 MiB，ZIP 中的图片解压后也适用此限制；图片与视频最多 16,777,216 像素，
单张静态图片解码时按需采样到最长边不超过 1024 像素，GIF 请求的目标大小为 1024 像素；
视频及固定布局的 Codex 图集不使用该采样路径。ZIP 只读 manifest 和指定图片，
不以 ZIP 条目名创建文件。通过文件选择器复制到应用内部并成功解码后才保存动画文件。
导入失败保留原列表与当前宠物。缓存按素材 ID 更新，不会继续显示旧图。
