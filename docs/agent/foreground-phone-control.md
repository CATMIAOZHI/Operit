# 前台手机操控

在工具包管理中启用“前台手机操控”（`phone_control`），主 agent 按需用 `use_package` 加载。
主对话使用 `phone_control:start` → `phone_control:observe` / `phone_control:act` → `phone_control:stop`。
start 已返回首次观察。每次 act 消耗一次观察编号，可以包含最多 20 个动作。
act 默认自动返回下一次观察编号，无需额外调用 observe，也不强制截图。
无障碍模式可由非视觉模型使用；截图模式需要视觉模型。截图和操作结果保存在普通工具记录里。

## 观察与批量操作

- `start/observe.mode=both`（默认）：截图附带控件文字、编号、中心点和边界坐标。
- `mode=accessibility`：只读控件，不截图；`mode=screenshot`：只看图，适合没有无障碍的游戏。
- `act` 兼容旧的单步 `action`，新增 `actions` 对象数组，两者二选一。
- 点击可使用 `element_index` 或 `x/y`。无障碍编号只属于返回它的观察，不是持久 ID。
- 可混合 tap、long_press、swipe、type、back、home、open_app 和 wait；wait 最多 2 秒。
- 每步检查会话、取消、屏幕尺寸与窗口身份；已识别控件检查该目标是否仍在原处。不比较整页布局，其他文本变化不影响目标按钮。纯视觉操作不要求无障碍信息。
- 不在批次中截图。`post_observe=auto` 默认优先沿用控件观察，无控件时截图；也可指定 both/accessibility/screenshot/none。
- 失败只结束剩余批次，保留操控会话，返回 completed_actions、attempted_actions、total_actions。已尝试的输入可能生效，不能直接重放整批。最后观察失败也会明确报告输入已完成。
- 批次执行最多 45 秒，最后观察最多 10 秒；本地超时保留上述进度，用户主动停止或取消仍立即终止会话。
- 批量只适合已经观察到、无需中途判断的目标。进入新页面或弹窗后应先观察，不猜下一页控件。系统窗口变化会中止剩余输入。

例如已观察计算器按钮后，六次 tap（1、2、×、3、4、=）可放进一次 act，最后返回结果文字。
外卖软件同页选数量可批量，进入规格窗后先观察再选择。回合制游戏可按截图发送已知坐标序列，
加入 wait 等待动画，最后截图决定下一回合；没有无障碍不会阻止批量操作。

## 第一版范围

- 主屏幕、当前主模型；不创建虚拟屏幕，不调用 UI_CONTROLLER 模型。
- 可单独开关，默认启用；停用工具包立即停止当前操控。工具定义不常驻默认内置工具目录。
- 包定义在 `examples/phone_control.js`，同步到 APK 的 `assets/packages`。内置包经宿主直接执行以保留真实主 agent 身份；普通脚本桥不能伪造调用。
- 点击、长按、滑动、输入、返回、桌面、打开已安装应用、短暂等待。
- 复用现有权限后端，需要输入和悬浮窗权限；无障碍观察需要界面读取权限，视觉观察需要截图权限，两者可任选。
- 不改写历史消息或系统前缀。旧对话需要用户刷新系统提示，或新开对话获取新工具目录。
- `run_ui_subagent` 及旧 UI 工具入口已停用，旧脚本收到迁移提示。主 agent 直接调用新工具；底层截图、输入实现继续复用，不经过旧脚本桥。
- 旧 UI_CONTROLLER 配置数据保留，但设置入口隐藏。

## 用户控制

复用旧主屏幕自动化的可拖动底部卡片，显示观察、操作、等待或失败状态，以及停止按钮。
不创建全屏触摸遮罩；卡片以外可正常触摸。主 agent 模式不显示未实现的暂停/继续按钮。
用户接管前应先停止操控，避免人工和 AI 同时操作。
卡片仍是局部悬浮窗，不保证目标应用不会检测到悬浮窗口。自动化输入不得点击卡片区域。

停止、取消、聊天结束或连续三分钟无工具操作都会释放控制权。
同一轮停止后不能重启；已注入系统的单个手势可能执行完毕，但不再提交后续操作。
轮次切换时释放旧会话；另一个对话不能使用旧会话。
不关闭目标应用，不强制返回 Operit。

## 记录与缓存

截图与控件坐标均使用原始屏幕像素。前台窗口身份独立读取，不依赖 UI 树导出。
截图时临时隐藏控制卡片与宠物；输入期间隐藏宠物，停止按钮仍可使用。
源截图缓存最多保留最近 100 张且总量不超过 64 MiB（当前一张除外）。
淘汰后，超出图片池保留范围的旧截图可能无法重新打开；文字操作记录保留。

## 验证

- 聚焦 JVM 测试：`PhoneControlLeaseTest`、`PhoneControlBatchTest`，验证停止、批次部分失败、窗口变化、目标变化、跨对话及迟到调用。
- 真机：新开视觉模型对话，打开无重要数据的应用，测试点击、中文输入、滑动、返回。
- 在模型思考和手势期间分别点击停止；确保按钮移除，本轮无法继续操控。
- 测试旋转或切换窗口后旧观察不能继续输入。
- 验证同时两个对话、subagent 调用均不能抢占。
- 真机安装使用 `adb install -r`，不清除用户数据。
# 批量操作体验

连续动作默认间隔 400ms，`step_delay_ms` 可设为 250–2000ms。打开应用后等待 700ms 再观察。
控件编号点击允许按唯一资源 ID、类型、文字重新定位，避免启动动画引起无效重观察；坐标点击仍核对原位置。
卡片会避开手势的完整纵向范围，无法避开的长滑动仅在该手势期间隐藏卡片。
批次失败也默认返回最新观察及已完成、已尝试数量，不能重放已尝试的动作。
完成、放弃或向用户提问前必须调用 `phone_control:stop`，回合结束自动清理仅作兜底。
