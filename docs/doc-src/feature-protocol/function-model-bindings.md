# 功能模型绑定

功能配置保存配置 ID 和具体模型名称；模型索引仅用于解析当前列表中的位置。
删除其他模型或调整顺序时，功能仍使用原模型。删除所选模型或整个配置后，该功能
显示“请重新选择模型”，新请求被阻止，不自动切换到默认模型或列表第一项。
用户重新选择后恢复使用；已经发出的请求继续使用其原有配置快照。

主聊天页顶部持续显示醒目提示条，列出缺少可用模型的功能（超过两项时显示总数）。
“去配置”直达功能模型配置页，修复后提示自动消失；其他已配置功能不受影响。
提示不进入聊天记录，不改变系统提示，也不显示在悬浮窗或只读审计对话中。

旧版仅含索引的设置在模型列表修改、删除或导入覆盖之前补存原模型名称。
没有模型名称要求的插件提供商仍可使用其原有空模型配置；删除曾选中的具体模型
不会退化到这一模式。权限风险评分器未单独配置时，仍按原规则跟随权限审核模型。

AI 的 `delete_model_config` 工具也保留失效绑定，返回受影响功能。
结果中的 `fallbackConfigId` 为空字符串，表示没有替代配置。

这项迁移无法还原升级前已经发生的模型误切换，用户需自行检查已有选择。
