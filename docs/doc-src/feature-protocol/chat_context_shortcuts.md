# 对话上下文与快捷操作

模型配置中的“模型上下文上限”描述接口支持的容量，单位为 K token。
聊天窗口有独立的预算：例如模型支持 1000K，可以只给当前聊天 300K。
实际使用不会超过模型容量。Max 开启时使用当前模型容量，关闭后恢复此前的自定义预算。

点击聊天顶部的上下文用量圆环，再选择“当前对话上下文”即可调整。
设置页只管理新聊天的默认值，不会覆盖已有聊天。分支继承父聊天的设置。
旧聊天首次使用时继承原模型设置；原有按轮数压缩规则可在聊天设置中关闭。

自动压缩默认开启，可在当前聊天或新聊天默认设置中关闭；不会覆盖已明确关闭的选择。
软件按有效预算和回复空间计算触发量；手填触发量过大时仍会提前压缩。
修改在下次请求生效，不影响已经开始的回复。

主动读取过的图片、音视频引用随当前上下文保留，不再按用户回合数移除。
统一压缩生成总结后，较早的媒体引用随被总结的历史退出请求；压缩不删除手机原文件和聊天记录。
实际媒体仍受现有媒体池的缓存容量和文件可用性限制；本规则不保证无限缓存或重启恢复。

在输入框开头输入 `/`，候选列表会显示快捷操作：

| 输入 | 点击候选后的操作 |
| --- | --- |
| `/compact` | 压缩当前聊天上下文 |
| `/autocompact 300K` | 设置自动压缩触发量 |
| `/autocompact auto` | 恢复软件自动计算触发量 |
| `/context 400K` | 设置当前聊天预算并关闭 Max |
| `/max on`、`/max off` | 开启、关闭 Max |

设置类命令省略参数时打开当前聊天的上下文设置。
必须点击候选才会执行；发送按钮和回车始终发送原文字给 AI。
原有工具包和技能候选仍然保留。
操作失败时保留输入，成功后仅清除未再编辑过的原命令草稿。
