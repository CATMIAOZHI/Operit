# 输入框语音听写

## 录音条

录音条显示最近 40 个音量样本，每 80 毫秒更新一次。新样本从右侧进入，
旧样本向左移动；低音量显示为点，不生成模拟音量的呼吸动画。
停止采集时冻结波形，开启新录音时清空；颜色跟随主题。

## ONNX 分段听写

- 输入框使用本地 ONNX 模型时，停顿约 2 秒后开始识别这一段。
  实际显示时间还包括设备上的模型推理时间。
- 识别与麦克风采集分开运行，识别上一段时仍可继续说话。
  各段结果按顺序换行追加；长文本可滚动查看，停止按钮保持可见。
- 点击停止：结束采集，等待已排队片段和最后尾段识别完成，再填入草稿。
- 点击填入：立即采用已经显示的文字，放弃尚未识别的音频。
- 点击取消：放弃这次录音，旧识别结果不能写入下一次录音。
- 上述操作不会自动发送聊天消息。

单段音频约 60 秒时自动切段，不结束整次录音。识别 worker 串行运行，
最多暂存两个待识别片段；若设备处理速度跟不上，会明确报错并保留已显示文字，
供用户填入草稿，不无限积压音频。长静音只保留最近 1 秒的起音上下文。

`supportsContinuousDictation` 是显式启用项，目前仅 ONNX 启用。
语音交互的单句结束策略、其他提供商的听写行为不受此开关影响。
