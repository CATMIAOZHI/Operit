# 存储管理

入口：设置 → 数据和权限 → 存储管理。

页面统计应用内部和外部私有目录的文件大小，分为聊天媒体、模型与组件、数据库、
图片预览缓存和其他文件。统计在后台运行，返回页面或点击刷新会重新统计。
不包含安装包、公共下载目录、用户工作区，也不重复计入终端符号链接指向的文件。
因此这里的数值与 Android 系统设置可能不同。

- 清理预览缓存：只通过图片加载器清理可重新加载的预览，不删除聊天媒体或工作文件。
- 组件管理：复用下载组件页面，支持查看和删除下载资源。
  已安装终端环境及其个人文件只计入占用，不在此删除。
- 历史记录管理与备份：使用已有入口。数据库删除记录后不保证立即释放文件大小。
- 其他文件包含设置、插件、附件源文件和临时文件，不提供全目录一键删除。

聊天媒体使用持久存储，图片 20 项、音视频 12 项的限制只用于内存缓存，
不会因超出该数量或重启自动删除磁盘附件。完整快照备份包含这些附件。
旧版本已经删除的图片，如果消息中保留的源文件仍存在，会在后台尝试恢复；
池文件和源文件都已丢失时，不能凭空恢复。
