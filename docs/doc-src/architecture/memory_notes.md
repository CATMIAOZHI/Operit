# memory.md 长期笔记

`memory.md` 存放一个记忆空间里需要经常带入对话的环境信息、项目约定和已验证经验，
上限为 6000 字符。用户身份和沟通偏好仍由全局 `user.md` 管理，详细资料仍保存在现有记忆库。
本功能不迁移或改写已有记忆。

## 使用入口

在记忆页面选择空间，点击“长期笔记 · memory.md”查看、编辑和保存。
保存时校验打开文件时的版本；若后台或另一调用已写入，显示最新内容并保留草稿，
用户核对后才能覆盖。超过容量不会保存，也不会自动删除旧笔记。

记忆库还有“改动审批”“对话历史搜索”“技能库”“提炼技能”“提取日志”入口。
这些入口打开应用内独立页面，使用顶部返回导航。历史全文也在页面中读取；
仅丢弃编辑等确认保留对话框，返回图谱保留原来的位置和选择。
“提炼技能”仅显示当前空间提炼并批准的技能，包含自动提炼和持续修订开关。
批准的技能可在全局技能库使用，所有权记录独立于可导入文件保存；手工导入不会获得后台修订身份。

## 工具包与开关

- `extended_memory_tools`：旧记忆图谱的查询、读取、增删改、关系管理和用户偏好工具。
- `memory_review`：新记忆工具。`notes` 读取或提出笔记改动，
  `history` 搜索、浏览和完整读取历史，`review` 列表、查看、审计、通过或拒绝；
  `manage` 读取和整理 memory.md/user.md，创建、修订技能及其附属文件，提出删除请求。

两个包在工具包页面分别开关，原生实现仍经过工具权限系统，不再默认列入系统工具清单。
关闭包控制 AI 工具可见性，不改变后台提炼开关。
原“自动保存记忆”改为全局总开关，沿用原保存值；关闭时阻止并取消所有自动提取，
包括图谱、笔记和技能，不改变独立路径的保存值，也不取消手动提取或人工审批。
“自动保存设置”页面提供总开关、全局图谱路径开关（默认开启）、当前空间的笔记和技能路径开关。
总开关开启后，各路径按自己的设置运行，关闭图谱路径不会关闭笔记或技能路径。
手动从历史搜索中提炼只生成新笔记/技能，不写旧图谱。

## 审批与历史

AI 和后台提出的笔记、技能先进入当前空间待审列表（最多30条）。
笔记替换/删除使用唯一原文，批准时再检查原文件版本，冲突不会覆盖新内容。
追加逐条去重；文件上限6000字符，写满不自动删除。
技能为带 frontmatter 的 SKILL.md，可维护 references/scripts/templates/assets 文本文件，
不执行生成的脚本。每次写入先读取版本，保存时再校验；不能更改技能身份或越出目录。
已批准的提炼技能在所属空间开启持续修订后可由后台自动修改，仍记录前后版本和审批历史。
删除整个技能或附属文件始终先提议，整目录删除校验文件清单版本。

用户可在审批页编辑、通过或拒绝。编辑会产生新ID，原草稿和旧审计保留为历史，
防止已审计内容被悄悄替换。手动编辑 memory.md 的保存也写入批准记录。
审批记录保留改动前后、审核者、时间、理由和审计意见；不随提取日志的容量限制删除。
应用前记录 applying 状态，中断后可重试，已完成决定幂等。

AI 可查看和添加审计意见；通过/拒绝还需要用户在审批页开启
“允许 AI 通过或拒绝当前空间的改动”（默认关闭），并填写决定理由。
原生工具在执行时强制检查该空间开关，模型参数不能代替授权。

## 后台提炼

旧图谱继续使用原候选队列与定时调度。新学习在前台回答结束后启动独立的隐藏子任务，
使用记忆模型，最多 12 次模型请求、40 次工具调用、180 秒；同对话开始新前台请求会取消它。
它只能使用本次授权的学习能力工具，先读已有内容再整理矛盾和重复，优先改进已有技能。
memory.md 和 user.md 的增改删生成待审记录；只有已批准且允许持续修订的提炼技能能自动写入。
提炼只针对可见普通主对话，不递归学习隐藏子任务。手动提炼使用同一执行器，
取消界面任务会取消提炼，运行状态和失败类别保存在提取日志。

## 对话搜索与提取日志

历史搜索直接查询已落盘的可见普通主对话，排除隐藏会话和子对话，
只返回用户/AI消息。普通关键词使用本地 FTS4 索引，CJK 查询自动使用包含匹配，
也可手动选择字面匹配。支持角色卡名称、发言角色、时间范围和会话筛选。
每页20条，搜索片段最多2000字符；上下文窗口可选，完整会话分页浏览，
长消息按8000个 Unicode 字符继续读取，含 NUL 的消息通过有界 UTF-8 字节块读取，避免 SQLite 在此截断正文。
不创建副本数据库，也不执行历史文本。
数据库 v34 为已有消息建立索引，并随消息增删改同步；不使用 Hermes 的 BM25 排序。
点击结果查看上下文后，可手动调用记忆模型提炼近期对话。

提取日志按空间持久化最近500次运行，记录开始/结束时间、来源对话、
旧图谱/笔记/技能开关、本次实际新增待审数、失败/取消和容量提示。
日志页每3秒刷新；不保存对话原文或模型原始输出。
没有结束时间仅表示尚无完成记录，应用退出后不会伪报成功。

## 存储与提示词

文件位于应用私有目录 `memory_notes/<空间ID的SHA-256>/memory.md`。
ID 不直接拼入文件路径。每个文件共用一个进程内互斥锁；写入前重新读盘，
通过临时文件、同步和原子重命名完成保存。审批记录位于 `memory_reviews`，
提取日志位于 `memory_extraction_logs`；文件名都使用空间ID的SHA-256。
删除空间时删除笔记、该空间审批历史和提取日志；已安装的全局技能不随空间删除。

构建系统提示词时，按请求指定空间、角色卡固定空间、全局当前空间的顺序选择。
沿用子任务个人上下文隔离策略，不向隔离子任务注入。
内容以转义后的背景资料块提供，不能覆盖用户当前要求。
“向新对话注入 memory.md”可单独关闭。系统前缀快照按对话 ID 持久保存，
聊天的 Classic 和 Agent 设置在“禁用 user.md”下方均提供“禁用 memory.md”，
控制实际选中的记忆空间，并与笔记页面的注入开关同步。它不删除文件、不影响自动提取。
群聊内再按角色执行身份保存，避免成员串用角色提示。新对话首次请求使用最新配置。
后台修改不重写旧前缀或旧消息。手动修改角色卡、user.md、笔记和相关提示设置时，
已有对话底部提示待重建，由用户点击后在下一请求加载最新版；生成期间禁止点击。
成功压缩后自动开始新快照，失败或取消压缩不刷新；重建、压缩均只影响当前对话。
切换模型导致工具调用协议不兼容时阻止发送并提示先重建；工具权限仍实时检查。
默认注入开关开启，AI审批授权默认关闭。
